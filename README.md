# Quiz Showdown (27)

Build a Jeopardy-style quiz web app.

Features:
- Start screen with game title
- Category selection
- 6 categories with 5 questions each
- Point values: 100, 200, 400, 600, 1000
- Jeopardy board layout
- Clickable question tiles
- Question modal
- Show answer button
- Correct / wrong buttons
- Player score tracking
- Support for 1–4 players
- Mark answered questions as disabled
- Responsive design for desktop and mobile
- Modern fun game-show style UI
- Use React, TypeScript and clean component structure
